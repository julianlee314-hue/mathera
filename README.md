# Mathera

Interactive universe map prototype — seven math worlds with zoomable skill maps.

## Live

https://julianlee314-hue.github.io/mathera/

## Worlds

| Era | Name | Skills (prototype) | Metaphor |
|-----|------|--------------------:|----------|

| II | Operate | placeholders | city |
| III | Relate | placeholders (locked) | bridges |
| IV | Solve | **199** | mountains |
| V | Prove | **173** | palace |
| VI | Motion | **174** | ocean |
| VII | Space | **197** | cosmos |

**IV–VII total: 743 skills** (titles invented to match domain outline; original paste unavailable).

## UX

Universe → World (all skills as dots) → zoom domain cluster → skill detail (steps a–d).

Pan/zoom: wheel + drag. Esc / double-click zooms out.
